# V1.4 版本说明

## 界面更新（2026-10-14）

- 白色产品栏、紧凑扫描汇总、文件明细与Study/Series页签，左侧结果、右侧详情。
- 文件表保持文件、模态、矩阵、状态、异常摘要五列。
- 正文和数字字体清晰，状态图标对齐，长文本与较矮窗口支持滚动。
- 鼠标使用整行选中，键盘使用细灰底线标识当前单元格；处理清单和复检表采用一致的焦点样式。
- 处理清单显示具体关联文件及相对路径预览，完整名单和路径可查看、复制或定位；批量编辑前展示问题数和去重文件范围。
- 保留人工状态、备注、审计、历史扫描、复检和四类全量CSV；检查证据与技术信息按需展开。

这些界面调整不改变DICOM规则、SQLite结构或复检判定。

## 主要变化

- 增加历史基线、重新发现与扫描，以及问题、文件和数量变化比较。
- 区分新出现、仍然存在、已解决、已忽略、需重新确认、无法确认和再次出现。
- 自动关闭仅针对有充分复检依据的已处理待复检问题；关闭、重开和重新确认保留备注及审计。
- SQLite schema 3支持v1/v2库事务升级，旧观察payload 1保持不变，升级失败回滚；不支持旧软件读取新结构或数据库降级。
- 增加comparison.csv，保留文件、序列和问题三类导出；历史报告固定对比时状态，重复比较同一批次对不重放系统动作。
- 修复Qt/GIL对象销毁锁反序，补充销毁线程及重复窗口压力测试。

## 演示与源码包

提供合成样例生成、阶段切换、自动回放、真实Qt截图和白名单源码打包工具。演示使用没有患者身份和PixelData的元数据文件，操作步骤见[合成演示指南](DEMO_GUIDE.md)。

源码包包含代码、测试、文档和合成截图，不含DICOM、CSV、SQLite、虚拟环境或私人工作记录。它是可安装依赖后运行的源码，不是exe安装包。

## 环境与限制

Windows、Python 3.12、pydicom和PySide6，无需GPU或在线模型。扫描离线运行，首次安装依赖可能需要网络。

测试结果与范围见[验证记录](VALIDATION.md)。项目不提供临床有效性、完整DICOM认证或全部磁盘故障恢复保证。项目暂未提供LICENSE，第三方依赖适用各自的许可证。
