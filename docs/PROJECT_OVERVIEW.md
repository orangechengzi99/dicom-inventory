# 项目定位

DICOMInventory 是面向影像数据准备与临床工程核对的本地桌面工具。它检查所选元数据中的读取、标识和序列一致性问题，提供事实、可能影响和核对建议，记录人工处理，再通过复检跟踪问题变化。

## 主要能力

- 按文件、Study和Series组织结果，根据对象类型选择适用规则。
- 区分读取成功、规则已检查、未评估、人工确认与复检结论。
- 为问题提供描述、影响、建议、证据、严重程度及关联文件定位。
- 将核心检查、GUI、SQLite、人工审计和比较分层，耗时任务在后台运行。
- 结合稳定问题键、证据和检查范围跟踪问题；删除文件、跳过规则或改变范围时保留无法确认的原因。
- 使用动态合成测试、事务故障注入、真实Qt流程和可重复演示验证功能。

## 与一般清点脚本的区别

工具不仅输出文件数量和异常标签，还支持发现问题、解释问题、记录人工处理、完整复检、比较结果及有依据地关闭问题。

这里描述的是项目的功能范围，不表示已完成与所有同类工具的性能比较或创新性评估。项目没有临床有效性研究或全市场比较结果。

## 适用边界

影像字段与几何规则支持所选传统单帧CT/MR对象，其他对象明确标注未评估。工具不提供像素诊断、自动修复、完整内容指纹、完整IOD认证、数据库加密或防篡改审计，当前也没有exe安装包。

主程序只读原始DICOM。演示脚本的阶段切换仅作用于生成器拥有的合成样例。合成数据验收说明工程功能可复现，不构成真实临床验证或部署认证。
