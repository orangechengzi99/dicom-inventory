## 复现测试

在项目根目录安装开发依赖后运行：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
$env:QT_QPA_FONTDIR = "C:\Windows\Fonts"
& ".\.venv\Scripts\python.exe" -B -m pytest -q -p no:cacheprovider
```

Windows离屏中文截图需要可用字体目录。真实硬链接防护用例需要测试目录支持创建硬链接；权限不足的失败属于未完成验证，不能解释为规则已通过。验收同时检查测试断言、警告/异常输出及原生退出码，不将断言通过但进程异常计为成功。
